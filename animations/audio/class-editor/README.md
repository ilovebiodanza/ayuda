# Audios del editor de Clases

33 segmentos MP3 agrupados en 9 capítulos.

Estado: voz generada provisional de Google Translate TTS.

El manifiesto `class-editor.manifest.json` agrupa los segmentos con el campo
`chapter` y contiene el título y el número de cada capítulo.

Para reemplazar la voz, conservar los nombres de los archivos y el manifiesto.
